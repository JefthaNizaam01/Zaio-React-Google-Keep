# Google Keep

A small Google Keep-style notes app built with React, Vite, and CSS.

## How to run

1. Install the dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the local URL printed by Vite.

Create a production build with `npm run build`.

## Features

- Add a note with a title, text, or both.
- View all notes and move notes to or from the archive.
- Search notes by title or text.
- Switch between grid and list note layouts.
- Notes are saved in the browser's local storage.
- Switch between light and dark mode. Your choice is remembered.
- Pin important notes to keep them at the top of the list.
- Add a date and time reminder to a note. Past reminders are marked as overdue.
- Delete notes you no longer need.

## New features in simple words

1. **Dark and light mode:** Press the mode button in the top bar. The app remembers your choice in local storage.
2. **Pin notes:** Press **Pin** on a note to move it to the top. Press **Unpin** to put it back in the normal order.
3. **Reminders:** Choose a date and time when creating or editing a note. The date appears on the note, and it is marked overdue when that time has passed.
4. **Delete notes:** Press **Delete** on a note to remove it.
